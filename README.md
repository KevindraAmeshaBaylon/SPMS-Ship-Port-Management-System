# SPMS – Ship Port Management System

## Overview
The Ship Port Management System (SPMS) is a software project developed to support ship port management operations.

## Technologies Used
- C#
- Windows Forms
- Microsoft Visual Studio
- SQL Server

## Project Structure
- `SPMS/` – Main application source code and Visual Studio project files.
- `pictures/` – pictures used in the application.

## Getting Started
1. Clone or download this repository.
2. Open the `.sln` solution file in Microsoft Visual Studio.
3. Restore any required dependencies.
4. Configure the database connection as required.
5. Build and run the application.
